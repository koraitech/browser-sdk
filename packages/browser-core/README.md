# `@koraitech/browser-core`

> **Internal package.** Shared building blocks for the Korai browser SDKs. It is not intended for direct use, and its APIs may change without
> notice.

To collect RUM data use [`@koraitech/browser-rum`][1]; to collect logs use [`@koraitech/browser-logs`][2].
