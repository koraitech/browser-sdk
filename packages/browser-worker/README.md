# `@koraitech/browser-worker`

> **Internal package.** Web Worker used by the Korai browser SDKs to compress intake requests off the main thread. It is not intended for direct use, and its APIs may change without
> notice.

To collect RUM data use [`@koraitech/browser-rum`][1]; to collect logs use [`@koraitech/browser-logs`][2].
